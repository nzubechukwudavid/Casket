# ABSTRACT

Ransomware is a critical challenge in the modern cybersecurity ecosystem, causing massive data loss and financial damage. While state-of-the-art deep learning approaches using Convolutional Neural Networks on PE header images show high accuracy, they require expensive GPU support, incur high latency, and operate as black boxes. To address this, this research proposed a computationally efficient solution by benchmarking ten machine learning models from four mathematical families—Gradient Boosting (XGBoost, LightGBM, CatBoost), Bagging (Random Forest, Extra Trees), Base Non-Linear (Decision Tree, SVM, KNN), and Linear/Probabilistic (Logistic Regression, Gaussian Naïve Bayes)—trained on four preprocessed PE datasets (58,547 samples) to evaluate accuracy, latency, and robustness against concept drift. All experiments were conducted on a standard CPU-only workstation.

The results demonstrated that ensemble-based gradient boosting classifiers achieve equal or superior accuracy compared to deep learning, using orders-of-magnitude lower computational complexity. Specifically, LightGBM achieved a peak F1-score of 0.9968 and 99.40% accuracy on parsed PE fields (training in <1 second, with 0.006 ms/sample inference latency and a size under 250 KB). On raw-byte sequences, LightGBM achieved 96.56% accuracy, outperforming GPU-trained literature baselines (93.73% for Xception CNN and 93.25% for LSTM). Statistical tests (t-tests and ANOVA) confirmed these gains are highly significant ($p < 0.001$), successfully validating the Green AI advantage in endpoint security.
